- Created `network_security_config.xml` to allow cleartext traffic for local PHP development (`10.0.2.2`).

- Set up **XAMPP** environment (Apache & MySQL).
- Created `donation_system` database and `users` table in phpMyAdmin.
- Developed `db_config.php` for PDO database connections.
- Implemented `login.php` with secure **BCRYPT password hashing** and verification.

## [2026-09-06] User Management
- Implemented **User Registration** flow.
- Created `RegisterActivity`, `activity_register.xml`, and `RegisterController`.
- Developed `register.php` with unique username validation and BCRYPT encryption.
- Added navigation links between Login and Register screens.

## [2026-09-07] Monorepo & Sync Strategy
- Created `backend/` and `sql/` folders in the project root to sync API code and database dumps via GitHub.
- Established a "Monorepo" workflow to allow seamless synchronization between multiple development machines (PC and Notebook).
- Planned the use of Symbolic Links (`mklink`) to connect the project's backend folder with the XAMPP `htdocs` directory.
